# Простой бот для приёма заявок от пользователя в MAX.
Некоторые наблюдения, которые я особенно прочувствовала в процессе создания именно этого бота (перечитаю в будущем =) ):  
* .gitignore - очень полезная вещь, если не хочешь утечки данных..  
* GitHub очень помогает в работе, если ты используешь несколько компьютеров для разработки.  
* TypeScript - это как JavaScript, только лучше, потому что помогает избежать ошибок из-за более чёткого определения типов.  
* Оказывается, есть утилита (PM2), которая сама рестартает бот, если тот вышибается по какой-либо ошибке со стороны VPS!
